# ONYX AppSafetyPolicy blocklist — shared by AppBridge (intents, share, notifications) and the screen tools.
# Load it with AppSafetyPolicy.default() (classpath resource) — never copy it.
#
# Format: one rule per line:   <category> <kind> <value>
#   category : payment | password_manager | authenticator | self | system_admin | store_purchase
#   kind     : package      exact package name
#              prefix       package-name prefix (e.g. "com.kotak")
#              word         a whole segment of the package name ("bank" matches com.foo.bank.app / com.foo_bank)
#              label        a whole word of the app's label ("Authenticator")
#              scheme       URI scheme (lower case, without "://")
#              host         URI host (and its subdomains)
#              action       Android intent action (screen/intent use)
# Lines starting with # are comments. Matching is case-insensitive.
# Categories marked "screen-only" in AppSafetyPolicy (store_purchase) do not block plain intents (opening the Play Store
# page of an app is fine; operating its purchase screen is not).
